E-Way Bill JSON upload

  1. Create bill in this app → Download E-Way JSON
  2. Go to https://ewaybillgst.gov.in
  3. Login with your e-way bill user ID
  4. e-Waybill → Generate Bulk
  5. Choose the JSON file and upload
  6. Verify and generate; print the e-way bill

Official bulk tools & schema: docs.ewaybillgst.gov.in/html/formatdownloadnew.html

Install on phone

Chrome → menu → Add to Home screen / Install app. Works offline after first open.
